# VocabX — что проверить руками перед пушем

Для владельца: то, что автотесты не покрывают или что надо увидеть глазами — пройти локально
(`pnpm dev` в `apps/web`, телефон в DevTools 390×844 и обычное окно), прежде чем пушить.
Каждая сессия плана дописывает свой раздел в конец (правило в `docs/PRELAUNCH_PLAN.md`,
«Handoff rule»). Проверенный пункт отметьте `[x]`; раздел, где всё отмечено, можно удалить.
Нашли проблему — напишите в чат номер сессии и пункт.

Формат раздела:

```
## Сессия N — <шаг>: <название> (<дата>, коммит <хеш>)
Перед проверкой: что подготовить (миграция, переменные .env, вход в аккаунт).
- [ ] Что сделать → что должно получиться.
Не проверить локально: что увидится только на Vercel (и как проверить там).
```

## Сессия 3 — 2.1a: лимиты запросов (2026-11-12, коммит 9ade788 + исправление после него)

Перед проверкой:

- `pnpm db:migrate` в `apps/web` — миграция `0005` (таблицы `rate_limits`, `translation_cache`).
  Локальный `.env` смотрит в основную базу, так что это та же миграция, что нужна до деплоя.
  Без неё «Знайти» не подсказывает перевод Google, а регистрация отвечает ошибкой.
- Локально все запросы считаются с одного «адреса» (`local`), поэтому лимиты общие для всех
  вкладок и браузеров на этой машине.

Перевод в форме слова («Мої слова» → «Додати нове слово» → «Знайти»):

- [ ] Без входа: слово → «Знайти» → есть варианты перевода (чипы) и примеры, как раньше.
- [ ] То же слово в окне инкогнито → варианты появляются сразу (общий кэш в базе).
- [ ] Без входа, в инкогнито: «Знайти» на 10–15 разных словах подряд, не быстрее ~20 слов в
      минуту → в какой-то момент под полем перевода текст «Безкоштовні підказки перекладу на
      сьогодні закінчилися. Увійдіть — і їх буде більше, 100 на день.» и кнопка «Увійти».
      Чипы из Wiktionary и примеры при этом могут остаться — так и задумано.
- [ ] Кнопка «Увійти» в этом сообщении открывает окно входа поверх формы; оно закрывается, форма
      со словом остаётся.
- [ ] Это сообщение на телефоне (390×844) и на десктопе: текст переносится, кнопка не налезает на
      поле «Приклад речення»; в тёмной теме текст читается.
- [ ] Импорт списка слов → «Заповнити все» на 20+ словах: часть слов может остаться без
      перевода (лимит), но сообщение «закінчилися» без исчерпанного дневного лимита не
      появляется, а вошедшему не предлагает войти.
- [ ] После того как лимит исчерпан: войти в аккаунт → «Знайти» снова подсказывает
      (у аккаунта свой счёт — 300 слов в сутки).

Вход и регистрация (Профіль → «Email»):

- [ ] Неверный пароль → «Неправильний email або пароль.» (без фразы про 15 минут).
- [ ] 10 раз неверный пароль к своему аккаунту → дальше «Забагато спроб. Зачекайте трохи й
      спробуйте знову.», даже с правильным паролем.
- [ ] После этого «Забули пароль?» → письмо → новый пароль → вход работает сразу (сброс снимает
      закрытие). Либо через 15 минут вход с правильным паролем снова работает.
- [ ] Регистрация и «Надіслати ще раз» работают как раньше; письмо приходит.

Режим разработчика (Налаштування → «Режим розробника»):

- [ ] Правильный код включает режим, как раньше. (11-й неверный код за 15 минут сейчас тоже
      пишет «Неправильний код.» — отдельное сообщение появится в 2.1b.)

База (Neon Console → Tables):

- [ ] В `rate_limits` ключи вида `translate:s:…`, `login:…`, `register:…`, `email:all`,
      `translate:all`: после двоеточия — хеш, ни IP, ни почты в открытом виде.
- [ ] В `translation_cache` — проверенные слова (`en|uk|revenue`) с переводами.

Не проверить локально (только после деплоя на Vercel):

- Счёт по реальному адресу отправителя (`x-real-ip`): с телефона по мобильной сети и с
  компьютера по Wi-Fi лимиты считаются отдельно.
- Кэш CDN для перевода: повторный запрос того же слова не доходит до функции (Vercel → Logs).
- Нагрузка на Neon: Neon Console → Monitoring, база засыпает, когда переводом никто не пользуется.

## Окно добавления слова: лист на телефоне, Enter, подсказка (2026-11-14)

- [ ] Открыть «Додати слово», нажать «Додати» с пустыми полями → под «Переклади» красная строка «Введіть слово та хоча б один переклад.»; ввести слово и перевод → строка исчезает сразу (при вводе только слова — остаётся, пока нет перевода). Закрыть и открыть окно → строки нет.
- [ ] Enter в поле слова → фокус в «Переклади», окно не закрывается и не сохраняется. Enter в переводах → слово сохраняется. Enter в «Приклад речення» → сохраняется, Shift+Enter → новая строка.
- [ ] Ввод с IME / голосовой диктовкой / автодополнением на телефоне: Enter, подтверждающий слово в клавиатуре, не перескакивает на следующее поле.
- [ ] Телефон (реальный, Android и iPhone): окно — нижний лист со скруглённым верхом высотой по содержимому, растёт вверх (например, когда появляются подсказки) и не выше видимой области; затемнённый фон виден над ним; заголовок и кнопки «Додати/Скасувати» закреплены, при нехватке места скроллится середина.
- [ ] Реальный телефон: тап в «Переклади» и «Приклад речення» — клавиатура не закрывает поле и кнопки (лист сжимается до видимой области); после закрытия клавиатуры лист возвращается к обычной высоте.
- [ ] Реальный телефон: потянуть шапку (заголовок) вниз больше ~90 px и отпустить → окно закрывается; меньше — возвращается на место. Кнопка ✕, «Скасувати» и системная «Назад» тоже закрывают.

- [ ] «Уменьшение движения» в ОС: окно не анимируется лишний раз (свайп следует за пальцем — это не анимация).

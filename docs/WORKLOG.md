# VocabX — журнал работ по предрелизному плану

Для владельца: история того, что сделано по `docs/PRELAUNCH_PLAN.md`, из которой потом собирается
итоговый отчёт. Новая запись добавляется в конец после каждого шага (правило 9 в плане).

Формат записи:

```
## <шаг> — <название> (<дата ГГГГ-ММ-ДД>, модель <F|O|S> или «владелец»)
- Зачем: одна строка — какую проблему закрывает шаг.
- Сделано: что изменено по сути (не пересказ диффа).
- Файлы: главные изменённые и новые файлы.
- Проверено: какие проверки прошли (typecheck/lint/test, e2e, скриншоты, ручная проверка) и что НЕ проверялось.
- Цифры: измеренные значения до/после, если есть; оценки помечены «оценка».
- Решения владельца: что было решено и почему.
- Осталось / риски: что отложено и куда (номер шага).
- Коммит: хеш, если был.
```
